## 🚀 Getting Started

### Prerequisites
- Python 3.7+

### Installation

```bash
git clone https://github.com/N1ksata/-Daily-Python-Snippets-repo.git
cd daily-python-snippets
```

### Running Examples

Navigate to any snippet and run:

```bash
python snippet_name.py
```
